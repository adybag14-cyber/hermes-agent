Agent is an independently maintained Android app for local AI chat and practical device workflows.

Choose a model first: open Settings > Models to import a GGUF, LiteRT-LM (.litertlm), or Android .task file with the system file picker. Local import requires neither an account nor an internet connection. Choose an imported or downloaded model and use the start action; the app selects the matching runtime. Model compatibility and available memory still determine whether a model can run.

Optional online providers and downloads are separate from local files. Response preferences, runtime controls, and advanced GGUF settings are grouped under clearly labelled expandable sections. Six interface languages, Android accessibility labels, and confirmation before removing a model help keep controls understandable.

The Full edition includes Android tools for files, app launch, accessibility-assisted actions, notifications, shortcuts, widgets, and automations. Permissions and remote processing remain opt-in. The Play edition has a more restricted tool set.

Agent is not an official Nous Research product and is not endorsed by Nous Research or Teknium. Open-source credits and licenses are retained. The existing application identifier is kept so installed users retain their upgrade path and app data.
